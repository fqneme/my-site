# Компьютер-Софт — сайт сервиса ремонта техники

Учебный проект: адаптивный сайт сервисного центра, заявки в SQLite, регистрация, вход и личный кабинет.

## Возможности

- адаптивная главная страница с услугами и ориентировочными ценами;
- отдельная страница контактов `/contacts` с порядком обращения и блоком частых вопросов;
- мобильная навигация и компоновка карточек для узких экранов;
- форма заявки с проверкой данных в браузере и на сервере;
- валидация номера телефона (от 7 до 15 цифр, без букв);
- регистрация по имени, электронной почте и паролю;
- проверка совпадения паролей и запрет повторной регистрации по одной почте;
- хранение паролей в виде хешей;
- вход и выход из аккаунта;
- личный кабинет с данными пользователя и его заявками;
- новые заявки авторизованного пользователя привязываются к его аккаунту;
- панель администратора: общая статистика по заявкам и аккаунтам;
- просмотр всех заявок, поиск по номеру/имени/телефону/устройству/email и фильтр по статусу;
- изменение статуса заявки из панели администратора;
- выгрузка заявок в Excel (.xlsx) с учётом поиска и фильтра по статусу;
- отдельная сводка в Excel: количество заявок, аккаунтов и распределение заявок по статусам;
- страница управления пользователями: поиск по имени/email/ID, просмотр роли и назначение/снятие роли администратора;
- запрет снять роль администратора с самого себя через панель;
- роль администратора назначается локальным скриптом `make_admin.py`, а не через открытую форму на сайте;
- CSRF-проверка POST-форм;
- SQLite: `data/site.db`.

## Технологии

- Python 3.15 (или совместимая версия Python 3);
- Flask 3;
- SQLite;
- openpyxl для формирования Excel-отчётов;
- HTML, CSS, JavaScript.

## Запуск в Windows / VS Code

1. Открой папку `computer_soft_site` в VS Code.
2. Выбери **Terminal → New Terminal**.
3. Установи зависимости:

   ```powershell
   py -m pip install -r requirements.txt
   ```

4. Запусти сервер:

   ```powershell
   py app.py
   ```

5. Открой `http://127.0.0.1:5000`.
6. Для регистрации нажми **Регистрация**, создай аккаунт и проверь личный кабинет.
7. Чтобы дать своему зарегистрированному аккаунту роль администратора, сначала останови сервер (`Ctrl+C`), затем выполни:

   ```powershell
   py make_admin.py
   ```

   Введи email аккаунта, который уже зарегистрирован на сайте. Скрипт работает локально и не создаёт отдельный пароль администратора. После назначения роли снова запусти `py app.py`, выйди из сайта и войди в этот аккаунт. Панель откроется по адресу `http://127.0.0.1:5000/admin`. На странице заявок есть кнопка «Скачать Excel», а ссылка «Пользователи» открывает `http://127.0.0.1:5000/admin/users`.

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## База данных и сохранность заявок

При запуске приложение создаёт таблицу пользователей и добавляет поле `user_id` к таблице заявок, если его ещё не было. Файл `data/site.db` не удаляется и существующие заявки не стираются. Заявки, созданные до регистрации, остаются в базе, но не появляются в новом личном кабинете, потому что ранее не были связаны с аккаунтом.

## Важное замечание

Проект предназначен для локальной демонстрации. Перед реальным размещением в интернете нужно задать уникальный длинный `FLASK_SECRET_KEY` через переменные окружения, отключить режим отладки и настроить HTTPS.

## Важные замечания

- При переносе обновления в существующий проект сохрани папку `data` и файл `data/site.db`: там хранятся заявки и аккаунты.
- Панель администратора предназначена для учебной локальной демонстрации. Не размещай `make_admin.py` на публичном сервере.
- Перед реальной публикацией нужно задать уникальный `FLASK_SECRET_KEY`, выключить `debug=True` и настроить HTTPS.

## Страница контактов и мобильная версия

Страница `/contacts` описывает способы обращения в сервис, порядок обработки заявки и частые вопросы. Форма и личный кабинет доступны через существующие страницы проекта. Адрес и телефон не указаны, чтобы учебный макет не выдавал вымышленные данные за реальные. Интерфейс адаптирован для узких экранов; навигация на мобильных устройствах открывается кнопкой меню.
